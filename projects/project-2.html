The Problem

Organizations need secure, scalable ways to share sensitive files without exposing them to the public internet. Managing user permissions, storage limits, and secure access links manually is complex and creates security vulnerabilities.

The Solution

This AWS-based storage solution leverages S3 for scalable file hosting and EC2 for the application layer. It implements a secure sharing mechanism using pre-signed URLs, ensuring that files are only accessible to authorized users for a limited duration, all monitored through CloudWatch logs.
